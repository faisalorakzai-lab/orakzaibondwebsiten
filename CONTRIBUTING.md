# Contributing to ORAKZAI GROUP

Thank you for your interest in contributing to the ORAKZAI ecosystem.

## Standards

- TypeScript strict mode, ESLint, Prettier enforced
- Conventional commits: feat, fix, chore, docs
- PRs require: clear description, linked issues, passing CI
- Never commit secrets or credentials

## Process

1. Fork the repository
2. Create feature branch: feat/your-feature
3. Commit using conventional commits
4. Open a Pull Request with detailed description

## Code of Conduct

Excellence, transparency, and respect in all contributions.
